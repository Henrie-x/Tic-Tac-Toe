Tic-Tac-Toe — Interactive Game

A browser-based Tic-Tac-Toe game featuring two playing modes: Player vs Computer and Player vs Player.

Overview

This project is an interactive implementation of the classic Tic-Tac-Toe game, built with JavaScript. Players can compete against another person or challenge a computer opponent.

Features

- Player vs Computer mode
- Player vs Player mode
- Interactive 3×3 game board
- Automatic winner detection
- Draw detection
- Computer opponent with basic decision-making logic
- Winning move detection
- Opponent winning move blocking
- Restart game functionality

Technologies

- HTML5
- CSS3
- JavaScript

How to Play

1. Open the game in your browser.
2. Choose Player vs Computer or Player vs Human.
3. Take turns selecting empty cells.
4. Get three matching symbols in a row, column, or diagonal to win.
5. Restart the game to play again.

Getting Started

Clone the repository:

git clone https://github.com/Henrie-x/Tic-Tac-Toe.git

Open the project folder and launch "index.html" in your browser.
